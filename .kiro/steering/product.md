# Product Overview

## What is Flutter?

Flutter is Google's open-source SDK for crafting beautiful, fast user experiences for mobile, web, and desktop from a single codebase. It enables developers to build natively compiled applications across multiple platforms using the Dart programming language.

## Key Features

- **Single Codebase**: Write once, deploy to iOS, Android, web, Windows, macOS, Linux, and embedded devices
- **Fast Performance**: Hardware-accelerated 2D graphics powered by Skia and Impeller rendering engines
- **Hot Reload**: See code changes instantly without restarting the app or losing state
- **Rich Widget Library**: Comprehensive set of Material Design (Android) and Cupertino (iOS) widgets
- **Layered Architecture**: Framework built in composable layers from low-level rendering to high-level widgets
- **Open Development Model**: Fully open source with active community contributions

## Target Users

- Mobile, web, and desktop application developers
- UI/UX designers seeking pixel-perfect control
- Teams building cross-platform applications
- Developers needing native performance with rapid iteration

## Repository Purpose

This repository contains the Flutter framework and command-line tools. The Flutter engine (C++, Java, Objective-C components) is maintained separately in the engine repository.
